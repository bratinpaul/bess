SOC Estimation Model

Build the SOC estimator: an extended Kalman filter (coulomb counting with a sensor-bias state, rested-OCV updates, FULL_CHARGE recalibration) plus LightGBM quantile corrections — scored against the soc_reference anchors and the flat mid-SOC region where it must beat coulomb counting. Use it on the SOC Estimator.

Corrections: coulomb SOC, raw & corrected current, pack / cell voltage, rested OCV and its implied SOC, cell temperature, usable Ah, C-rate, coulombic efficiency, at rest & rest minutes, time and Ah since the last recalibration, current direction — plus the EKF SOC, sd, bias and gain for the hybrid.
