Fault Classifier

Fault classification & diagnosis on the confirmed fault episodes: a signature / Bayesian engine that needs no training (the fault_signature library scored against each window) fused with a LightGBM / XGBoost classifier on telemetry, signature, alarm and context features - scored out-of-fold by episode and forward in time, then calibrated. Results, Pareto and fishbone are on the Fault Diagnosis viewer.
