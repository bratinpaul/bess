Historical Load

Load a folder of historical telemetry files (BMS, PCS, EMS, HVAC, module, alarms, dispatch events) for any site through the bulk-load APIs. Existing rows are updated, so a folder can be loaded again safely.

  1. Select the site and parameters
  2. Check the files
  3. Include / exclude files
  4. Start the load
  5. Monitor it with Refresh status
