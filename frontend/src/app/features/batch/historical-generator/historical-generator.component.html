Historical Generator

Generate historical telemetry files (BMS, PCS, EMS, HVAC, module, alarms, dispatch events) for one or more sites from the sample files in input\historical, in the same layout as the Bhadla BESS folder. Ratings and asset codes come from master data; you can adjust them for a run without changing master data.

  1. Select sites and the date range
  2. Review the mapping and scenarios
  3. Generate
  4. Monitor it with Refresh status
